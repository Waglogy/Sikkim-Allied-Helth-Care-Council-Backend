Backend REST API Reference

Base URL: http://localhost:8080 Framework: Spring Boot 4.1 Content-Type: application/json Endpoints: 34 Generated: 2026-08-25
Authentication. Security is stateless and configured as an OAuth2 resource server validating self-issued JWTs (HS256). Public routes: /api/auth/**, /error, GET /api/files/** (serving uploaded files) and GET /api/category/** (the public council directory). Every other endpoint requires a valid token. Obtain a token from POST /api/auth/login, then send it on protected requests as:
Authorization: Bearer <token>
Tokens are signed with subject = admin email, carry a roles claim, and expire after app.jwt.expiration-minutes (configurable).

  "success": true,

  "data": { /* endpoint-specific payload (T) */ },
  "timestamp": "2026-08-24T10:15:30.482Z"
}
Validation error — ApiError (HTTP 400)
{
  "success": false,
  "message": "Validation failed",
  "errors": {
    "email": "email must be a valid email address.",
    "password": "password must be at least 8 characters long."
  }

19. Upload a file

POST /api/upload auth required
Uploads a single image or PDF to Cloudflare R2 and returns its public URL. Send as multipart/form-data with a file part. Images are stored under uploads/img/, PDFs under uploads/documents/. The returned url is what you store on a member / event / message / publication / notification.
Request — multipart/form-data
// field "file": the binary image or PDF
// allowed: JPG, PNG, WebP, GIF, PDF · max 10 MB
curl -X POST /api/upload \
  -H "Authorization: Bearer <token>" \
  -F "file=@photo.png"
Response — 201 Created
{
  "success": true,
  "message": "File uploaded successfully",
  "data": {
    "url": "http://localhost:8080/api/files/uploads/img/…png",
    "fileName": "photo.png",
    "contentType": "image/png",
    "size": 20482
  },
  "timestamp": "2026-08-25T10:15:30.482Z"
}
The url is a direct R2 URL when R2_PUBLIC_BASE_URL is configured; otherwise it points at the backend file proxy (below). Bad type / oversized files return 400.

20. Serve an uploaded file

GET /api/files/{key} public
Streams an uploaded object back from R2 with its original content type (public, read-only) so <img> tags and links work without a token. The {key} is the object path, e.g. uploads/img/…png. Returns 404 for an unknown key. Only used when no public R2 URL is configured.
