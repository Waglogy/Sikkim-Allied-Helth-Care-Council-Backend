Authentication state. Security is stateless and configured as an OAuth2 resource server. Only /api/auth/** is public — every other endpoint requires authentication. Note: the codebase currently exposes POST /api/auth/signup only; there is no login / token-issuing endpoint yet, so the protected routes below cannot be reached until one is added.
Endpoints

  • POST /api/member — Create a member auth

Standard response shapes
